## Relay Forge

## Local Setup

- Ensure you have Node.js installed in your system
- Install dependencies, we use pnpm so make sure you have that installed otherwise install it from here

```
curl -fsSL https://get.pnpm.io/install.sh
```

- Create a .env file and add all the properties from .env.example file. Make sure you have correct details of those properties

- Run local server using

```
pnpm run dev
```
